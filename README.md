## What it does

`main.ts` (Node 22, standard library only) writes one original line — the funniest one-line confession an AI agent could make — to `/output/entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out-confession node main.ts
cat /tmp/out-confession/entry.txt
```
